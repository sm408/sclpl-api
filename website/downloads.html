CORE RUNTIME

SCLPL v1.0.1

The workflow engine, SCLPLL parser, CLI, scheduler, built-in functions, and bundled plugins.

Download wheel ↓python -m pip install sclpl-1.0.1-py3-none-any.whl

Requires Python 3.11 or newer. Optional extras: [data], [keyring], [crypto].

pip install "sclpl[data]"      # pandas-backed tables, Excel, Parquet
pip install "sclpl[keyring]"   # OS-keyring secret storage
pip install "sclpl[crypto]"    # encrypted-file secrets, no keyring daemon needed
sclpl doctor                   # sanity-check the local environment
