Two repositories, one language authority. sclpl-api owns the parser, runtime, and CLI; sclpll-extras builds editor and plugin tooling on top of it — nothing here is a "coming soon."

REPOSITORIES

RepoWhat's in it
sm408/sclpl-apiThe language authority: parser, formatter, runtime, CLI, bundled functions. MIT licensed, current release v1.0.1.
sm408/sclpll-extrasCompanion distribution: VS Code extension, SCLPLL language server, plugin packages (azure_blob), the bundled-function catalogue, and a workflow library. No second parser — it runs on the installed sclpl package.
