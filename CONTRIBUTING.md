# CONTRIBUTING.md

## Before changing the project

Read:

- `AGENTS.md`
- `FEATURES.md`
- `ARCHITECTURE.md`
- relevant files in `requirements/`

## Contribution expectations

- keep changes aligned with local-first and Python-first doctrine
- respect architecture boundaries
- update docs when architecture or contracts move
- add or update ADRs for meaningful decisions

## Documentation honesty rule

Do not document planned features as implemented features.
