# NON_GOALS.md

SCLPLAPI should not become:

- an Electron-heavy desktop shell by default
- a cloud-locked API SaaS
- a mandatory telemetry product
- an enterprise workflow maze
- a giant low-code platform clone
- an AI-black-box automation tool
- a multi-user distributed system before single-user local-first quality exists

Early-phase hard stops:

- no visual workflow builder before runtime stability
- no plugin marketplace
- no remote account system
- no speculative microservice split
