# Workflows

Workflows are first-class execution graphs in SCLPLAPI.

## MVP progression

- sequential chains
- loops and variables
- conditions and retries
- graph execution
- visual editing

## Rules

- workflow definitions are explicit
- runtime behavior is deterministic
- visual tooling does not outrun the runtime model
