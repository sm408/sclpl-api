# Graph Report

The graph report is the normalized representation of a workflow run.

## Includes

- workflow metadata
- node execution order
- node outcomes
- timing summary
- retry/failure data
- produced outputs

## Uses

- UI execution review
- analytics
- export generation
- debugging
