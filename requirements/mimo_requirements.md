# MiMo Requirements

SCLPLAPI must ship with project-local MiMo assets that help future implementation sessions stay aligned.

Required assets:

- root `AGENTS.md`
- project `mimocode.json`
- project-local skills in `.mimocode/skills/`
- project-local agents in `.mimocode/agents/`
- project-local tools in `.mimocode/tools/`
- supporting rules in `rules/`

Those assets must reinforce:

- local-first doctrine
- workflow-first runtime sequencing
- strict core / flexible UI discipline
- documentation honesty
