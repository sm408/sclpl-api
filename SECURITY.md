# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. This project is currently
pre-1.0, so users should keep installations and dependencies up to date.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for this repository when available. Include the affected version, reproduction steps,
impact, and a suggested mitigation if you have one.

Never include real credentials, tokens, or private data in a report or fixture.
